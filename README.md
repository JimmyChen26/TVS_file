# TSV 資料檔讀取程式

## 專案簡介

本專案是一個使用 C# Windows Forms 製作的 TSV / TXT 資料檔讀取程式。

程式可以讓使用者透過功能表開啟 `.tsv` 或 `.txt` 檔案，讀取檔案中的單字資料，並將資料顯示在 `ListView` 表格中。

每一筆單字資料包含：

- 單字
- 音標
- 音檔路徑
- 解釋
